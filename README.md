# Zoltraak - NeoForge 1.21.1

## Build
1. Cai JDK 21.
2. Tai MDK chinh thuc: https://github.com/NeoForgeMDK/MDK-1.21.1-ModDevGradle
   Copy `gradlew`, `gradlew.bat` va thu muc `gradle/` tu MDK vao thu muc nay.
3. Chay:  `./gradlew build`   (Windows: `gradlew.bat build`)
4. File jar: `build/libs/zoltraak-1.0.0.jar`

## Cai dat
Bo jar vao thu muc `mods/` cua server VA cua moi nguoi choi (client).

## Su dung
- `/give @s zoltraak:zoltraak_staff`
- Chuot phai: Zoltraak (tia tim)
- Shift + chuot phai: Zoltraak Barrage (nham vao ke dich trong 20 block)
